## 🧹 Before Publishing a Repository

Before making a repository public, I always verify:

* No passwords
* No tokens
* No API keys
* No sensitive `.env` files
* No unwanted private domain names
* No sensitive public or internal IP addresses
* No unnecessary personal identifiers
* Presence of `.gitignore`
* Presence of `README.md`
* Presence of `.env.example` file if necessary
